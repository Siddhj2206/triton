Notes
How the window behaves
Rules
Re-skin, never re-layout
The window is a stock two-pane adaptive layout so it can ship as a real libadwaita app.
Mica sidebar, solid pane
Navigation floats on the wallpaper. Controls sit on a solid surface so text never competes with the sky.
Grouped rows
2 px gaps, 24 px outer corners, 6 px inner. The only radius in a tiled window is inside its content.
Settings apply live
No Apply button. Changes run through matugen and a toast reports which targets finished.
Search first
Every setting is indexed. Typing anywhere in the window starts a search.
Narrow windows
Below 860 px the sidebar becomes a full-width list and each page slides in over it.
