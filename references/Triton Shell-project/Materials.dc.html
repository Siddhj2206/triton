Glass Floating

Use for
Bar, quick settings, menus, OSD, floating windows. Things that sit above work.
Fill
surface-container-high at 70%, blur 32px, saturate 1.5, brightness .85, 1px top highlight
niri
xray false. Sees the windows below, so use it sparingly.
Rules
No glass on glass. If text drops under 4.5:1, go solid.
