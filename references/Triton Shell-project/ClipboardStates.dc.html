Rules
How clipboard history behaves
Super+V, centered
A floating Thick Glass panel. It closes on paste so focus returns to the app you were in.
List left, preview right
Hover or arrow keys move the preview. The list never changes width.
Private by default
Sensitive items are masked, held in memory and wiped. History clears at logout unless you keep it.
Local only
Nothing syncs. Images live in the cache directory, not in your documents.
Plain text paste
Shift+Enter strips formatting. Links paste as the URL, never the title.
Reduce motion
Items fade instead of spring in. The panel itself opens in 120 ms.
