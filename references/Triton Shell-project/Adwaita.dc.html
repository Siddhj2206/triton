Re-skin, never re-layout
Color, shape and material change. Spacing, sizes and widget structure do not, so GNOME apps keep working after updates.
Blur is opt-in per window in niri, so apps that don’t match stay solid.
GTK3 apps get the same palette from a second matugen template.
